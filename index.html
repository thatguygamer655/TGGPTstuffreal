Gimmick

A personal YouTube automation tool.

Gimmick is a small self-hosted tool that runs on its operator's own computer. It does two things for the one channel it is connected to:

  • Daily poster — uploads one queued video per day and keeps a running day counter, for "day N of posting this until X" style accounts.
  • Comment bot — replies in character when a viewer mentions the bot by name in the channel's own comment section.

This is not a hosted service. There is no Gimmick website that stores your data, no account to sign up for, and no server operated by anyone. Each person who uses it runs their own copy on their own machine and connects it to their own YouTube channel.

Google account access

Gimmick connects to YouTube through Google's standard OAuth consent flow. It never asks for or handles a Google password. The access it requests is limited to uploading videos to, and reading and replying to comments on, the channel of the person running it.

See the privacy policy for exactly what is accessed and where it is stored.

Contact

Questions about this tool go to the operator who set up the copy you are dealing with — they control the installation, the queue, and the bot's personality.
