Privacy Policy

Last updated: 24 August 2026

Gimmick is not a hosted service. It is a program that runs on the operator's own computer. There is no Gimmick server, no database, and no company receiving your information. Nothing described below is transmitted to the authors of this software.

What Gimmick accesses

When the operator connects their Google account, Gimmick requests permission to:

  • Upload videos to the operator's own YouTube channel.
  • Read comments on that channel's videos, including the commenter's public display name and public comment text.
  • Post replies to those comments as the channel.
  • Read basic channel details — the channel's name, ID, and avatar — used to display which account is connected and to avoid the bot replying to itself.

Gimmick requests no access to Gmail, Drive, Contacts, location, payment details, or any Google product other than YouTube.

Where data is stored

Everything stays on the operator's computer, in the folder where Gimmick is installed:

  • state/tokens.json — the Google OAuth access and refresh tokens.
  • state/commenter.json — the IDs of comments already replied to, so the bot does not reply twice.
  • state/poster.json — which files have been posted and the current day number.
  • .env — the operator's own API keys.

These files are never uploaded anywhere. Gimmick has no telemetry, no analytics, and no crash reporting.

Comment text and AI models

To write a reply, Gimmick sends the text of the comment it is replying to, the commenter's public display name, and the video's title to whichever AI provider the operator has configured — for example Google Gemini, OpenRouter, Anthropic, OpenAI, or a model running locally on the operator's own machine.

That provider's own privacy policy governs what happens to that text. Operators who prefer no third party to see comment text can configure a local model, in which case nothing leaves the machine at all.

Only comments that mention the bot by name are sent. Comments that do not mention it are ignored and never leave the machine.

Limited use of Google user data

Gimmick's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Specifically, data obtained from Google APIs is used only to provide the features described above, is never sold, is never used for advertising, and is never transferred to anyone except as necessary to provide those features.

Data retention and deletion

The operator controls all retention. Deleting the state/ folder removes every stored token and record. Access can also be revoked at any time from Google Account permissions, which immediately and permanently invalidates Gimmick's access.

Children

Gimmick is a developer tool and is not directed at children.

Changes

If this policy changes, the date at the top of this page will change with it.

Contact

Enquiries should go to the operator of the specific installation you are dealing with, using the support email shown on the Google consent screen when you granted access.
